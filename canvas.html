Onda Volunteer Project

A comprehensive summary of all implemented vertical slices (tracer bullets) and features to build the volunteer management platform.
Slice 1–7

Platform Tracer Bullets + Auth

Initial API foundation, schema, test harness, and JWT-based Supabase authentication cycle.

Slice 8–14

Web Shell Epic

Initial web client structure, routing with TanStack Router, layout context, i18n plumbing, and shell navigation placeholders.

Slice 15

Organization Context Reads

API endpoint to fetch accessible Churches, Campuses, and Ministries for the logged-in Volunteer.

Slice 16

Identity Persisted UI Locale

Persisting the language switcher preference to the user's Identity profile automatically upon change.

Slice 17

Dashboard Upcoming Assignments

Dashboard presentation of assigned shifts matching the active Church, including a live API feed.

Slice 18

Time Away List + Create

Volunteer capability to view their upcoming unavailabilities and submit new blockers for their ministries.

Slice 19

Bulk Mirror Unavailability

Expanded Time Away logic to let a volunteer mirror unavailability periods across all their active ministries simultaneously.

Slice 20

Scheduling Event List

Church-scoped schedule index, merging PUBLIC events with accessible PRIVATE events based on ministry memberships.

Slice 21

Event Roster Read

Deep-dive view for a specific Event, rendering all active assignments grouped by Ministry, Role, and Time.

Slice 22

Event Roster Assign & Release

Interactive capability to let Leaders assign active members to roles, and let Volunteers (or Leaders) release those assignments.

Slice 23

Leader Unavailability Writes

Extended authorization permitting a Ministry Leader to record unavailability on behalf of their team members.

Slice 24 & 25

Event Creation

Enabling Church Admins to schedule PUBLIC events, and Ministry Leaders to schedule PRIVATE rehearsal/prep events.

Slice 26

Pending Membership UX

Surfacing a dashboard warning for volunteers who have "PENDING" ministry memberships waiting for approval.

Slice 27

Role Catalog

Ministry Leader UI to manage their roster roles (adding new titles, renaming inline, and retiring old roles).

Slice 28

Event Cancellation

Admin feature to instantly cancel an Event, visually striking it out and cascading a void to all related assignments.

Slice 29

Personal-Local Time Toggle

A non-destructive global toggle allowing users to render schedule instants in their device's local timezone alongside the primary Church framing.

Slice 30

Auth Gate + Provisioning

The full sign-in cycle that automatically creates or links a Volunteer record to a Supabase authentication token.

Slice 31–33

HOPE Design System Migration

Full-scale UI overhaul pivoting from the "Lamborghini" prototype to the brutalist "HOPE" visual system with sharp corners and heavy borders.
